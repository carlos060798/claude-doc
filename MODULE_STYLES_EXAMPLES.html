Cómo usar estos estilos

  1. Copia el contenido de module-styles.css al final de styles.css
  2. Usa las clases en tu HTML como se muestra en estos ejemplos
  3. Verifica en responsive redimensionando el navegador
  4. Personaliza colores editando las variables en :root si es necesario

Documentación completa: Revisa MODULE_STYLES_GUIDE.md para instrucciones detalladas.
