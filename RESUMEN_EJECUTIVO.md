## LA PROPUESTA: 5 Cambios de Contenido

### CAMBIO 1️⃣: Microlearning Dashboard + Adaptive Paths

**Objetivo:** Reducir fricción cognitiva, crear mini-victorias

**Qué hace:**
- Fragmenta secciones L4+ en micro-lecciones de 5-10 min
- Dashboard muestra progreso granular (4/12 micros vs 35% nivel)
- Recomendación automática: "Siguiente micro: 8 min"
- Streak de días consecutivos (🔥 x7)

**Impacto esperado:**
- Session duration: 45 min → 120 min (estudiante se queda más)
- Completion L4-5: 35% → 60% (+25 pp)
- Dashboard visits: +15% semana (senso de progreso)

---

### CAMBIO 2️⃣: Feedback Loop Inline + Remediation

**Objetivo:** Diagnosticar gaps, ofrecer soluciones rápidas

**Qué hace:**
- Pre-quiz antes de leer sección (3-5 preguntas)
- Estructura: lectura (600w) → quiz inline (2q) → lectura → ejercicio
- Feedback inteligente: si score < 70% → link a repaso (5 min), no re-leer todo
- Ejercicios interactivos: "escribe manifest.json", valida regex, feedback inmediato

**Impacto esperado:**
- Quiz completion: 40% → 75% (+35 pp)
- Time-to-next-level: 180 min → 120 min (-1 hora)
- Remediation usage: baseline → 45% (estudiantes aceptan ayuda)

---

### CAMBIO 3️⃣: Gamification + Visual Progress (Badges, Streaks)

**Objetivo:** Motivación extrínseca sostenida + tangible recognition

**Qué hace:**
- 11 badges por nivel (desbloqueables): "MCP Builder", "Debugging Master", etc.
- Daily streak: 🔥 x7 = badge "One Week Warrior" + 25 XP
- Progress ring en dashboard (65% completado con SVG animado)
- Notificaciones al desbloquear: "Ganaste 'Architecture Visionary' 🏗️ (+50 XP)"

**Impacto esperado:**
- Session frequency: 2x/week → 4x/week (streak motivation)
- Completion rate: 60% → 75% (milestones claros)
- Social sharing: 5% → 25% (mostrar badges en LinkedIn/Twitter)

---

### CAMBIO 4️⃣: Real-World Capstones + Portfolio

**Objetivo:** Demostración práctica + artefactos para carrera

**Qué hace:**
- Nivel 2: "Build CLI Tool" (4h) — repositorio + CLAUDE.md + cost breakdown
- Nivel 4: "Multi-Agent System" (8h) — arquitectura + código + observability
- Nivel 6: "Enterprise Adoption" (20h) — roadmap + training materials + governance
- Portfolio: `/portfolio` muestra capstones + badges + certificados descargables
- Peer review: L4+ estudiantes revisan otros capstones (mejorar calidad)

**Impacto esperado:**
- Capstone submissions: baseline → 50%
- Completion L5-6: 40% → 65% (motivación de "algo real")
- Portfolio shares: baseline → 35% (tangible achievement)

---

### CAMBIO 5️⃣: Community Hub + Post-Mastery Roadmap

**Objetivo:** Networking + retención post-L6

**Qué hace:**
- Community Hub: tabs Proyectos | Q&A | Tips | Job Board
- Estudiantes comparten capstones, votan, comentan
- Post-mastery paths: "AI en Hiring", "AI en Finance", "MCP Ecosystem"
- Job board: empresas contratando "Claude Code Architects"
- Mentorship matching (L6 → L3-4 mentores)

**Impacto esperado:**
- Post-mastery retention: 5% → 40% (siguen aprendiendo)
- Community submissions: 25% de estudiantes
- Job placements: 3+ contrataciones vía plataforma
