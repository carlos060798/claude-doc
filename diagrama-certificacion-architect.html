⚠️ 18+ Anti-Patrones Arquitectónicos

Errores Comunes en Loops

  • ❌ Sin halt conditions (loops infinitos)
  • ❌ Ignorar stop_reason
  • ❌ Context window unlimited

Errores en Tool Design

  • ❌ JSON-Schema incompleto
  • ❌ Sin validación de entrada
  • ❌ Timeouts no configurados

Errores en Orquestación

  • ❌ Sin circuit breaker
  • ❌ Context leakage entre agents
  • ❌ No retry logic

Errores en Prompting

  • ❌ Prompts no validados
  • ❌ Sin formato estructurado
  • ❌ Tokens excesivos

Errores en Context Mgmt

  • ❌ Sin cache strategy
  • ❌ RAG sin filtrado
  • ❌ Embeddings outdated

Errores de Deployment

  • ❌ Sin canary deploy
  • ❌ No rollback plan
  • ❌ Cost uncontrolled

💻 Ejemplo de Código: Agent Loop Básico

# Claude Certified Architect - Agent Loop Pattern import anthropic import json client = anthropic.Anthropic() def run_agent_loop(task: str, max_iterations: int = 10): """ Agent loop básico con halt conditions Demuestra: stop_reason handling, tool use, context awareness """ messages = [ {"role": "user", "content": task} ] tools = [ { "name": "search_knowledge_base", "description": "Buscar en base de conocimiento", "input_schema": { "type": "object", "properties": { "query": {"type": "string"}, "limit": {"type": "integer"} }, "required": ["query"] } } ] iteration = 0 while iteration < max_iterations: iteration += 1 # Call Claude with agentic behavior enabled response = client.messages.create( model="claude-opus-4-7", max_tokens=2048, tools=tools, messages=messages ) # Check halt condition: stop_reason if response.stop_reason == "end_turn": print("✅ Agent completed task") return response.content[-1].text elif response.stop_reason == "tool_use": # Process tool calls tool_results = [] for content in response.content: if hasattr(content, 'type') and content.type == "tool_use": print(f"🔧 Tool call: {content.name}") # Execute tool (simulated) result = f"Result for {content.name}" tool_results.append({ "type": "tool_result", "tool_use_id": content.id, "content": result }) # Add assistant response and tool results to messages messages.append({"role": "assistant", "content": response.content}) messages.append({"role": "user", "content": tool_results}) else: print(f"⚠️ Unexpected stop_reason: {response.stop_reason}") break print("❌ Max iterations reached - potential infinite loop") return None # Ejemplo de uso if __name__ == "__main__": result = run_agent_loop( "Analiza estos datos y proporciona un resumen ejecutivo" ) print(f"Resultado final: {result}")
