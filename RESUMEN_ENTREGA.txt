================================================================================
CARACTERISTICAS PRINCIPALES
================================================================================

COMPONENTES
   - Secciones (.module-section) con padding y bordes
   - Titulos jerarquicos (h2-h5) con estilos distintivos
   - 5 tipos de cajas destacadas (note, warning, example, tip, info)
   - Listas avanzadas (con iconos, caracteristicas, pasos)
   - Tablas profesionales (data-table, comparison-matrix)
   - Grillas responsive (grid-2, grid-3, grid-auto)
   - Elementos expandibles (details/summary estilizados)
   - Badges y etiquetas (6 variantes de color)
   - Bloques de codigo (ya en styles.css, referencias incluidas)

DISENO
   - Basado en tokens CSS existentes (colores, espaciado, tipografia)
   - Paleta: Naranja Claude (#ff7a59), Azul (#5eb8ff), Verde, Ambar, Rojo
   - Espaciado en grid de 8px (--sp-1 a --sp-12)
   - Tipografia: Inter (sans-serif), Fira Code (monospace)
   - Bordes y sombras sutiles (profesional, no agresivo)

RESPONSIVO
   - Desktop (1280px+): Layout completo, grids multi-columna
   - Tablet (768px): Grids simplificados, padding reducido
   - Mobile (375px): Single column, fuentes legibles
   - Scroll horizontal para tablas grandes

ANIMACIONES
   - fadeIn - Aparicion de secciones (0.4s)
   - slideInLeft / slideInRight - Entradas laterales (0.3s)
   - scaleIn - Aparicion con escala (0.3s)
   - Respeta prefers-reduced-motion (accesibilidad)

ACCESIBILIDAD
   - Contraste WCAG AA garantizado
   - Etiquetas semanticas (<strong>, <em>, <details>)
   - Soporte para lectores de pantalla
   - Prefiere colores + texto sobre solo iconos

================================================================================
COMO INTEGRAR (2 OPCIONES)
================================================================================

OPCION 1: Copiar en styles.css (RECOMENDADO)
───────────────────────────────────────────
1. Abre module-styles.css - Selecciona TODO (Ctrl+A) - Copia (Ctrl+C)
2. Abre styles.css - Ve al final (Ctrl+End) - Pega (Ctrl+V)
3. Añade comentario separador antes de pegar:
   /* MODULE SECTIONS STYLES */
4. Guarda (Ctrl+S)
5. Recarga index.html en navegador (F5)
6. ¡Listo! Usa las clases en tu HTML

OPCION 2: Archivo separado
──────────────────────────
1. Deja module-styles.css en la carpeta raiz
2. En index.html, despues de <link rel="stylesheet" href="styles.css">
   añade: <link rel="stylesheet" href="module-styles.css">
3. Guarda y recarga
4. ¡Listo!
