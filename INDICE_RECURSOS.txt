================================================================================
FLUJO DE USO DIARIO
================================================================================

DURANTE DESARROLLO:
  - Documenta en JSDoc
  - Escribe tests
  - Crea ejemplos si es importante
  - npm run verify:all

ANTES DE COMMIT:
  - npm run format
  - npm test
  - npm run test:examples
  - npm run test:docs

PARA PR:
  - git checkout -b feature/tu-feature
  - Haz cambios
  - npm run verify:all
  - Haz PR

CUANDO REVIEWS:
  - Usa CODE_REVIEW_CHECKLIST.md
  - Verifica 10 puntos
  - Merge cuando todo OK

PARA PUBLICAR:
  - node scripts/bump-version.js [patch|minor|major]
  - npm run verify:all
  - git push origin --tags
  - npm publish

ERRORES COMUNES Y SOLUCIONES
================================================================================

Error: validate-examples.js falla
Solución: Verifica que archivos en examples/ sean ejecutables

Error: validate-docs.js falla
Solución: Añade funciones a API.md o actualiza lista en validate-docs.js

Error: GitHub Actions no ejecuta
Solución: Verifica que archivos estén en .github/workflows/

Error: npm publish falla
Solución: Verifica NPM_TOKEN y que package.json tenga versión correcta

Error: No sé qué escribir en docs/API.md
Solución: Empieza con el JSDoc de tu código
