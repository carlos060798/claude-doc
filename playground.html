🎯 Dónde Usar Este Prompt

Guarda el output como CLAUDE.md en la raíz de tu proyecto para que Claude lo use como system prompt automáticamente en cada sesión.

bash 
# Guardar en tu proyecto
cat > CLAUDE.md << 'EOF'
[pega tu prompt generado aquí]
EOF

# Verificar que funciona
cd tu-proyecto && claude
# Claude leerá CLAUDE.md automáticamente

💰 Modelos y Precios (aprox.)
Opus 4.7Máxima calidad. Razonamiento complejo.
Sonnet 4.6Equilibrio ideal. Recomendado por defecto.
Haiku 4.5Rápido y económico. Tareas simples.
Regla: Usa Haiku para volumen, Sonnet para calidad, Opus para razonamiento profundo.

🔥 Patrones de Prompt más Efectivos

PatrónCuándo UsarEjemplo
Chain of Thought Problemas complejos de lógica "Piensa paso a paso antes de responder..."
Role + Constraint Definir comportamiento del agente "Eres un DBA. NUNCA ejecutes DROP sin confirmar..."
Format Directive Outputs estructurados "Responde SOLO en JSON con campos: status, result, errors"
Few-Shot Tareas con formato específico "Ejemplo entrada: X → salida: Y. Ahora procesa: Z"
Minimal Privilege Agentes en producción "allowed-tools: [Read, Grep] — NO Write, Edit, Bash"
